📄 EN ORIGINAL — UR E26 Overview

Each IACS member society has developed its own cyber security guidance and certification programs building upon UR E26.

While UR E26 sets the minimum mandatory requirements, class societies offer additional voluntary notation/certification programs with enhanced requirements.

Ship owners and operators should understand the differences between class societies when selecting classification and when planning for compliance.

🇰🇷 한국어 해석 (Korean Interpretation)

각 IACS 회원 선급은 UR E26을 기반으로 자체 사이버 보안 가이드라인과 인증 프로그램을 개발하였다.

UR E26이 최소 의무 요건을 규정하는 반면, 각 선급은 강화된 요건을 포함한 추가적인 자발적 등급/인증 프로그램을 제공한다.

선주·운영사는 등급 선택과 준수 계획 수립 시 선급 간 차이를 이해해야 한다.

🇯🇵 ClassNK NK Ship Cybersecurity Guideline (2024)
★★★★★
인증: CyberSecure 심사
4단계 건조 검사 체계(설계→FAT→건조→시운전). 연차·갱신 심사 구분. 개별 CBS별 상세 요건 명시.
💡 가장 체계적인 4단계 심사 프로세스. 한국·일본 조선소 주 적용 선급.
🇬🇧 LR LR Rules Pt.6 Ch.1 (Cyber Security)
★★★★
인증: Cyber Security Notation
LR-RU-001 규정에 E26 내용 직접 편입. 기념일 전후 3개월 연차 검사. 신조선 엄격 적용, 기존선 단계적 적용.
💡 영국 선주·P&I 클럽과 관계 깊은 선박 선호. LR Cyber Security Review 절차 사전 숙지 필요.
🇺🇸 ABS ABS CyberSafety (2024)
★★★★
인증: CyberSafety Notation
5개 Sub-goals 기반. 연차 보고서 + 현장 감사 병행. 침투 테스트 결과 요구(일부). CSMS 절차서 상세 요구.
💡 미국 선주·LNG선·유조선 선호. ABS CyberSafety 포털 사전 등록 필요.
🇳🇴 DNV DNV Cyber Secure (2024)
★★★★★
인증: Cyber Secure Notation
Cyber Secure Basic/Enhanced/Advanced 3등급. F031 ZCD 양식. 자체 평가 + 원격 검토. CSMS 프레임워크 연동.
💡 북유럽 선주·크루즈·LNG 선호. 가장 상세한 요건이나 가장 많은 지원 자료 제공.
🇫🇷 BV BV NI 641 (Cyber)
★★★
인증: Cyber-Resilient Ship
NI 641 지침 기반. VeriSTAR 포털 제출. 군함·특수선 별도 가이드라인 보유.
💡 프랑스 선주·특수 선박(요트·군함·해양플랜트) 선호.
🇮🇹 RINA RINA Cybersecurity Rules (2024)
★★★
인증: Cyber Resilience Notation
E26 요건 직접 적용. 지중해 선주 대상 컨설팅 지원 강화.
💡 지중해 지역 선주 선호. 페리·크루즈 선박 적용 사례 증가.
🔬 Insights — Maritime Cybersecurity Expert
선급 선택 기준 권고
선급 선택은 단순히 '가장 엄격한 선급'이 아닌 선주의 운항 경로·용선사 요구·보험사 요건·향후 매각 시장을 고려해야 합니다. 한국·일본 발주 신조선은 ClassNK 또는 LR 선호. 북유럽 발주·LNG선은 DNV 선호. 미국 시장 타겟은 ABS. 복수 선급 병행 등록(Dual Class)도 검토 가능하나 비용·이중 감사 부담.
선급별 요구 문서 차이 핵심 정리
ZCD 추가 항목: DNV = Security Profile 추가 / ClassNK = CBS 카테고리 컬러 코딩 / ABS = CSMS 절차 참조 추가. CSDD 추가 항목: DNV = CSMS 프레임워크 매핑 / LR = Change Management 섹션 필수 / ABS = Risk Assessment 통합 요구.
