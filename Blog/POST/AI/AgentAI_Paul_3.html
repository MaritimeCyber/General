Part 1 — Foundational Technology
ReAct · Tool Calling · MCP: The Standards That Make Agent AI Possible

1. ReAct — How Agent AI Thinks

ReAct is a pattern proposed in a 2022 paper from Princeton and Google that defines the most basic way Agent AI operates. It's short for Reasoning + Acting.

💡 The Core Idea of ReAct

Traditional LLMs only reasoned ("here's what should be done"). ReAct makes it alternate between reasoning and acting.

Thought: I need to check this vessel's ECDIS version
Action: [DB lookup] Search vessel A's ECDIS version
Observation: ECDIS v2.1, last updated 2023.06
Thought: No update for over two years. Need to compare against IACS E27 requirements
Action: [Search] IACS E27 ECDIS update requirements
Observation: Annual patch review required; core navigation systems recommended to update within 6 months
Thought: Non-compliant status. Classify as an immediate-action item
Result: Log it in the risk report as a High Priority item

ReAct is still used as the default pattern in most Agent AI systems today. Simple yet powerful, and it has the advantage of letting humans easily trace the intermediate steps.

2. Tool Calling — The Standard Way LLMs Use Tools

Tool Calling (or Function Calling) is a standardized method for an LLM to call external functions (tools). Since OpenAI introduced it with GPT-4 in 2023, it has become an industry standard.

How Tool Calling Works
①

The developer defines a tool: tells the LLM about a function called "vessel_db_search(vessel_id, query)"

②

The LLM decides to call it when needed: "I need vessel data → I should use vessel_db_search"

③

The function executes: the actual system queries the DB and returns a result

④

Interpret the result: the LLM understands the returned data and decides the next action

The LLM doesn't execute code directly. It requests "please run this function with these arguments," and a separate system carries it out.

3. MCP (Model Context Protocol) — The 2024 Game-Changer

In November 2024, Anthropic released MCP (Model Context Protocol), a standard that changed the Agent AI ecosystem. While Tool Calling had each company connecting tools its own way, MCP is a USB-like standard that lets every AI connect to every tool in the same way.

💡 Before MCP vs. After MCP
Before MCP
  • Each company connects AI to tools its own way
  • Code has to be rewritten every time a new tool is added
  • Locked into a specific AI model
After MCP
  • Any AI connects to tools the same way
  • Adding a new tool is as simple as installing an MCP server
  • No need to reconfigure tools when switching AI models

As of 2025, MCP servers already exist for Slack, GitHub, Google Drive, and various ERP systems. In the maritime industry too, momentum is building to connect AIS data, class society portals, and vessel monitoring systems via MCP.

🚢 What MCP Means for the Maritime Industry

Build an MCP server for the IACS regulation database just once, and Claude, GPT, Gemini — any AI — can query the latest regulations in the same way. Just like standardized parts in shipbuilding, the AI ecosystem is becoming standardized too.

Part 2 — Leading Frameworks
AutoGPT · CrewAI · LangGraph: Comparing Agent-Building Tools

4. AutoGPT — The Pioneer of the Agent AI Era

AutoGPT, which appeared in March 2023, was the first project to show the public the idea that "give GPT-4 a single goal, and it does the rest on its own." It hit 100,000 GitHub stars within a week of release.

✅ What Was Innovative

The first implementation of the "fully autonomous" concept, where AI decides and executes the next action without human intervention. Combines internet search, file management, and code execution to perform complex tasks.

⚠️ The Limits

It often lost direction and fell into loops, or burned through excessive, unnecessary cost. It showed that a "fully self-sufficient AI" wasn't a finished concept yet — but it kicked off explosive growth in Agent AI research.

5. CrewAI — AI That Works as a Team

CrewAI was the fastest-growing agent framework of 2024. The core idea is simple: "Several AIs with clear roles working as a team beats one all-purpose AI."

CrewAI Example: A Vessel Cybersecurity Audit Team
📋
Regulation Analyst Agent

Dedicated to analyzing the latest IACS, DNV, and LR regulations. Specialized to this role alone.

🚢
Vessel System Inspection Agent

Dedicated to querying the vessel CBS database and assessing the current state.

⚠️
Risk Assessment Agent

Takes the outputs of the previous two agents and dedicates itself to gap analysis and risk rating.

📄
Report Writer Agent

Dedicated to compiling all results into a professional audit report.

Because each agent focuses on its own specialty, result quality improves dramatically over a single agent.

💡 A Maritime Industry Analogy

Just as a navigator, chief engineer, and cargo officer each hold a specialized role on a ship, CrewAI has each AI take a specialized role and collaborate as a team. A team with a division of labor beats a jack-of-all-trades working alone.

6. LangGraph — Precisely Controlling Complex Flows

LangGraph is a framework built by the LangChain team that lets you precisely control an Agent AI's execution flow as a graph structure. It's well suited to building advanced agents that need complex branching, loops, and parallel execution.

Framework Comparison
Framework Characteristics Best Suited For Difficulty
AutoGPT Fully autonomous, minimal setup Exploring simple autonomous tasks Low
CrewAI Role-based multi-agent Simulating team collaboration Medium
LangGraph Graph-based precise control Complex business workflows High
Part 3 — Multi-Agent & Agent OS
Systems Where Multiple AIs Collaborate: The Future of Agents

7. Multi-Agent Architecture — A Team Beats a Loner

A Multi-Agent system is a structure in which several AI agents communicate and collaborate to achieve a complex goal. Each agent holds a specific role, exchanges information with the others, and divides labor toward the overall goal.

Multi-Agent Architecture — A Maritime Cybersecurity Platform
👑 Orchestrator Agent (Conductor)
Grasps the overall goal and distributes tasks to sub-agents
↓ ↓ ↓
🔍 Threat Detection Agent
Real-time network monitoring
📋 Compliance Agent
Checks IACS/IMO regulations
📧 Reporting Agent
Automated stakeholder reporting
↓
🛡 Response Agent
Automated isolation and response upon threat detection

Each agent runs in parallel, autonomously managing vessel cybersecurity around the clock.

8. Agent OS — The Operating Infrastructure for AI

For multiple agents to run reliably, communicate with each other, share resources, and recover from errors, management infrastructure is needed. This is called an Agent OS.

💡 What an Agent OS Does
→

Agent Scheduling: Manages which agent runs when

→

Memory Management: Manages shared memory across agents versus each agent's individual memory

→

Tool Access Control: Manages permissions on which agent may use which tool

→

Monitoring & Logging: Records agent actions, detects errors, escalates to a human

→

Cost Optimization: Coordinates agent execution to minimize API call costs

Currently, Anthropic's Claude Agent SDK, Microsoft's AutoGen, and Vertex AI Agent Builder all serve the role of an Agent OS. 2025–2026 is the period when competition over this infrastructure is fiercest.
