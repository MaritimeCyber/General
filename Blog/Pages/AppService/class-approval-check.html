What is Type Approval (TA)?

Type Approval is the official certification issued by a classification society confirming that marine equipment meets required safety, reliability, and performance standards for installation aboard vessels. Equipment such as navigation systems, fire detection devices, communication equipment, and safety systems must hold a valid TA certificate from the ship's class society before installation.

For vessels trading globally or classed under multiple bodies, cross-checking TA status across different societies is essential during procurement, class renewal, and flag state inspections.

💡 Search Tips

Keep this page open: Each Search → button opens in a new tab, so you can return here and check the next society without losing your place.
Search strategy: Start with the manufacturer name (e.g. Furuno), then narrow by product type (ECDIS) or model number. Some sites search by model number only.
Vessel's class society first: Always verify with the vessel's registered class society — their TA is mandatory. Approvals from other societies are supplementary.
Certificate validity: TA certificates expire. Always check the validity date and revision status on the official certificate page before procurement.
Language tips: KR (e-MESIS) and ClassNK return best results with official English model names or the manufacturer's English trade name.

🔧 If Something Goes Wrong

🔗 Link Not Opening
Each society card's Search → button is a direct link that opens in a new tab. If a link fails, right-click → "Open in new tab" as an alternative.
🌐 Site Unavailable
Some society databases (RINA, CCS, KR) may be intermittently unavailable. Try again after a few minutes. For CCS, the China mainland server is sometimes slow outside Asia.
❌ No Results Found
Try the manufacturer's official English brand name or registered trade name. Check spelling. Search by product category if manufacturer search fails. Contact the society's local office as a last resort.

About the Classification Societies

🇯🇵 ClassNK
Japan's largest class society. Mandatory for Japanese-built vessels and a leading approver across major Asian fleets.
🇳🇴 DNV
Norwegian-based global leader. Dominant in offshore, energy, and complex maritime systems including OT cybersecurity standards.
🇬🇧 Lloyd's Register (LR)
UK-based society with strong global reach. Specialises in naval architecture, offshore platforms, and critical marine systems.
🇺🇸 ABS
American Bureau of Shipping. Dominant for US-flagged vessels and offshore oil & gas platforms in the Gulf of Mexico region.
🇫🇷 Bureau Veritas (BV)
French-based global society. Strong presence in passenger vessels, superyachts, and French-flagged commercial fleets.
🇰🇷 Korean Register (KR)
Korea's national class. Required for vessels from Hyundai HHI, HD KSOE, Samsung SHI, and major Korean yards.
🇮🇹 RINA
Italian registry. Covers Mediterranean shipping, cruise industry, superyachts, and Italian naval vessels.
🇨🇳 CCS
China Classification Society. Essential for Chinese-built vessels and COSCO, CSCL, and CMHI fleet groups.
🇵🇱 PRS (Polski Rejestr Statkow)
Polish Register of Shipping. Covers Polish-flagged and Baltic Sea vessels. Active in EU flag state recognition programs.
