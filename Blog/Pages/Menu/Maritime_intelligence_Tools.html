Frequently Asked Questions — Maritime Intelligence Tools

Are these maritime tools free to use?

Yes. All 9 tools in this suite are free, require no account or sign-up, and are maintained by ShipPaulJobs as part of the site's maritime technology and cybersecurity coverage.

Which classification societies does the Type Approval Check cover?

The Class Type Approval Check tool searches official Type Approval databases across 9 major classification societies from a single search interface.

How current is the data behind these tools?

Tools marked LIVE — Maritime Cyber Compliance AI, Maritime Weather, Visitor Intel, and Vessel & Fleet Analysis — pull from live sources on every visit (open-meteo, VesselFinder AIS, and connection metadata). Ship Order Trends and Maritime Cyber Threat Intel refresh from Clarksons/industry data and curated threat feeds on a regular cadence.

Where can I find IACS UR E26/E27 and other compliance documents?

The Maritime Cybersecurity Docs library indexes IACS UR E26/E27, BIMCO, NIST SP 800, class society rules, and national port security regulations, split into International, Class, and National sub-sections.
