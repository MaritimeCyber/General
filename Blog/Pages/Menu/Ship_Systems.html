Key Ship System Categories

Navigation
Integrated Bridge Systems & ECDIS

Electronic chart display, conning displays, AIS/ARPA integration, voyage planning. Mandatory under SOLAS. Subject to IACS UR E26 cyber requirements.

Propulsion
Engine & Propulsion Automation

Integrated automation systems (IAS), engine monitoring, remote control, shaft power monitoring, fuel consumption optimization, IEC 62443-aligned OT security.

CBS
Computer-Based Systems (CBS)

IACS UR E26 defines CBS as any onboard computer-based system affecting safety, propulsion, or cargo. All CBS must be inventoried, assessed, and protected under the cyber resilience plan.

Networks
Onboard IT/OT Networks

Ship LAN/VLAN design, OT network segmentation, firewall architecture per IACS UR E26, NMEA 0183/2000 data buses, satellite connectivity (VSAT, 5G).

Safety
Safety & Fire Detection

Fire detection, public address, general alarm, fixed gas/fire suppression systems, and GMDSS communications — all within IACS E26 cyber scope for newbuildings.

Cargo
Cargo & Ballast Management

Cargo control and monitoring systems, ballast water management (BWMS per IMO D-2), loading computer systems, and tank gauging automation.

Frequently Asked Questions — Ship Systems

What does IACS UR E26 require for ship systems?

IACS UR E26 (effective 1 July 2024) requires all newbuilding contracts to include cyber resilience measures across shipboard systems. This covers asset inventory and classification, network segmentation, security zones and conduits, access control, software patch management, and security incident response procedures.

What is a CBS (Computer-Based System) in maritime?

CBS is the IACS UR E26 term for any onboard system using computer hardware and software — navigation displays, engine management systems, ballast control, cargo systems, and more. All CBS must be inventoried, risk-assessed, and protected as part of the vessel's cyber resilience plan.

What is NMEA 2000 and why does it matter for ship cybersecurity?

NMEA 2000 (IEC 61162-3) is the CAN-bus based navigation data network used by bridge instruments. Without proper network segmentation, a compromised NMEA 2000 node could inject false navigation data. IACS UR E26 specifically addresses protection of navigation-critical data buses.

Ship Systems — Vessel Technology & Cybersecurity

Ship Systems covers the design, integration, and cybersecurity of onboard vessel systems under IACS UR E26/E27 requirements. Special focus is given to how each system class must be identified, documented, and protected in compliance with current class society rules.
