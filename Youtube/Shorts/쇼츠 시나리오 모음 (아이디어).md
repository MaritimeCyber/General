# ShipPaulJobs Shorts

> Big Ships, Simple Answers — Ocean Science Explained So Simply, Even a Kid Gets It.

## 🎯 제작 방향성

**모든 대본은 "초등학생도 한 번에 이해할 수 있는 수준"을 기준으로 작성합니다.**

- 어려운 용어(Rudder, Displacement, AIS 등)를 먼저 던지지 않습니다 — 먼저 **누구나 아는 것과 비교**해서 궁금증부터 만듭니다. (예: "자동차엔 핸들이 있는데, 배는?")
- 설명은 **"왜?"에 대한 답 하나**로 끝냅니다. 여러 개념을 한꺼번에 욱여넣지 않습니다.
- 전문 용어는 화면 자막으로 **이름만** 보여주고, 나레이션은 쉬운 말로 풀어씁니다.
  - 예: 자막 "Buoyancy" → 나레이션은 "물을 밀어낸 만큼 배가 떠요" 처럼
- 반전/의외성이 있는 주제(4번, 8번, 9번처럼)를 우선합니다 — 아이들이 가장 잘 반응하는 포인트입니다.
- 마무리는 항상 **"그래서 신기하죠?"** 톤으로 — 가르치려 하지 않고 같이 놀라는 느낌으로 끝냅니다.

**컷 종류에 따라 도구를 다르게 씁니다.** 모든 컷을 AI 영상으로 만들 필요는 없습니다.

| 태그 | 의미 | 왜 |
|---|---|---|
| 🎥 **Kling** | 실사풍 컷 — Kling으로 제작 | 자연스러운 카메라 움직임·질감 표현에 강함 |

| 🎥+🎨 **Kling+오버레이** | 실사 기반 Kling 클립 위에, 화살표/라벨만 후반 편집으로 얹기 | 배경은 실사가 자연스럽고, 설명용 화살표만 정확하게 별도 레이어로 |

각 주제의 컷 프롬프트 앞에 이 태그를 표시해뒀습니다.

**Kling 사용 순서 (컷 1개 기준)**
1. 프롬프트로 스틸 이미지 1장 먼저 생성 (Midjourney/DALL-E 등, 9:16 세로 비율, 위 스타일 가이드 색감 적용)
2. 마음에 드는 프레임 확정 → **바로 text-to-video보다 이 방법을 추천**합니다. 구도가 매번 랜덤하게 나오는 걸 막아주고, 10개 숏츠 전체의 톤을 통일하기 쉬움
3. 확정한 이미지를 Kling **image-to-video**에 업로드 + 카메라 움직임(줌아웃, 패닝 등, 프롬프트에 이미 명시됨)을 추가로 지시 → 5~10초 클립 생성
4. 컷 길이가 10초를 넘는 경우(6컷 구성의 마지막 컷 등) → 클립 2개를 만들어 이어붙이거나 Kling의 extend 기능 사용

**조립(편집)**
1. 나레이션 녹음/TTS (위 나레이션 보이스 가이드 기준, 45초 분량)
2. **CapCut** 추천 — 무료, 세로 숏츠에 최적화, 자동 자막 기능 있음
3. Kling 클립 + 모션그래픽 컷을 나레이션 순서대로 배치, 타이밍 미세조정
4. 자막 스타일 통일(브랜드 폰트/색), 저작권 없는 배경음악 살짝
5. 마지막 로고 컷 확인 후 9:16 세로로 export

**배치 작업 팁**: 한 주제씩 처음부터 끝까지 만들지 말고, **이미지 전체 먼저 → Kling 영상화 전체 → 모션그래픽 전체 → 편집 전체** 순서로 묶어서 진행하면 도구를 왔다갔다하는 시간이 줄어듭니다. (10개 주제 총 53컷 중 대략 절반이 🎥 Kling, 절반이 🎨 모션그래픽/오버레이입니다.)
